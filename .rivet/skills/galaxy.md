# 星河 (Galaxy) — 集群执行环境

你已进入星河模式。当前任务需要拆解为多个独立维度并行执行。

## 激活流程

1. **分析任务** — 先读相关代码，理解模块边界和依赖关系
2. **拆解维度** — 确定 2-5 个可并行的子任务（如前端 + 后端 + 审查）
3. **选择星域** — 每个维度指派一个合适的星域：
   - 前端/UI → 文曲
   - 后端/逻辑 → 天机
   - 架构/规划 → 天权
   - 实现/编码 → 天梁
   - 审查/验证 → 瑶光
   - 探索/实验 → 破军
   - 重构/优化 → 天府
   - 数据/对账 → 开阳
   - 文档/调研 → 天璇
   - 统筹/编排 → 天枢
4. **展示方案** — 调用 galaxy({confirm: false}) 展示集群方案，等待用户确认
5. **启动执行** — 用户确认后，调用 galaxy({confirm: true}) 启动集群
6. **汇总交付** — 所有分子 Agent 完成后，审查维度统一验证，汇总报告

## 注意事项
- galaxy 工具在子 Agent（worker）中可用，主 Agent 先 delegate 到子 Agent 再在内部启动星河
- 同一维度多个星域（authorities 数组）共享房间，互相感知同伴身份
- 自动追加的审查维度（瑶光）会等所有执行维度完成后再运行，并进行**同房间互审**——交叉对比共享房间内各星域的产出，标注一致点、冲突点和互补点
- 聚合策略默认 all_required，所有维度必须通过
- 结果包含跨维度冲突标注（如前后端接口不一致）
